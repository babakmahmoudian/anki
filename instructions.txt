My-German-Adjective:Deutsch|English|Aussprache|Beispiel
My-German-Adverb:Deutsch|English|Aussprache|Notiz|Beispiel
My-German-Noun:Deutsch|English|Aussprache|Genus|Plural|Beispiel
My-German-Paradigm:Deutsch|English|Paradigm|Notiz|Beispiel
My-German-PragmaticExpression:Deutsch|English|Aussprache|Kontext|Beispiel

My-German-Conjunction:Deutsch|English|Aussprache|Verbstellung|Notiz|Beispiel

PHASE 1: CLASSIFICATION & ESSENTIALS (All Note Types)

    1. Auto-detect word type.

    2. Identify target Note Type; default to the most common usage if ambiguous.

    3. Fill Deutsch, English, Aussprache. Aussprache should be enclosed in brackets (e.g. [lant]).

PHASE 2: STRUCTURAL FIELDS (Type-Specific)

My-German-Verb {
    Imperativ field: must contain the three Imperativ forms for "du", "ihr", and "Sie/sie".

    Präsens and Präteritum fields: must include exhaustive full conjugations for all persons; e.g. "esse, isst, isst, essen, esst, essen".

    Verbtyp field: schwach, stark, gemischt, unregelmäßig.

    Kasusregierung field: specifies the case governance of the verb; can be none, one, or multiple of (akkusativ, dativ, genitiv, reflexiv).

    Hilfsverb field: The auxiliary verb used for the Perfekt tense (haben or sein).
}

My-German-Adverb {
    Notiz field: a free-form field in English including short usage notes, rules, and extra information and explanation. It may contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
}

My-German-Noun {
    Deutsch field: should not contain the article. 

    Genus field: der, die, das.

    Plural field: standard plural form without article (e.g., Sohn→Söhne). Leave empty if no plural exists (e.g., uncountable nouns like "die Milch").
}

My-German-Paradigm {
    Paradigm field: all four cases for all genders and the plural.

    Notiz field: a free-form field in English including short usage notes, rules, and extra information and explanation. It may contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
}

My-German-PragmaticExpression {
    Kontext field: a free-form field in English describing all the social situations or conversational functions. It may contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
}

My-German-Conjunction {
    Verbstellung field: koordinierend, subordinierend

    Notiz field: a free-form field in English including short usage notes, rules, and extra information and explanation. It may contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
}

My-German-Preposition {
    Regiert field: multiple (Dativ, Akkusativ, Genitiv, Dativ/Akkusativ, Dativ/Genitiv, Akkusativ/Genitiv, Nominativ).

    Verwendung field: a free-form field in English including short usage notes or rules;  It may contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary;
        - e.g. for "zu": "used with people, buildings, institutions;<br>emphasizes direction toward.".
}

PHASE 3: BEISPIEL GENERATION (Type-Specific Rules)

Each deutsch example on a new line and enclosed in <b></b> tags, folowed by a <br>, and the Enlish translation without formatting on the next line;
    - e.g. for "Auge": "<b>Mein Auge tut weh.</b><br>My eye hurts.<br><b>Sie hat blaue Augen.</b><br>She has blue eyes."

My-German-Preposition {
    Must include an example for each Regiert field value.
}

PHASE 4: ERROR REDUCTION MECHANISMS

Mandatory checklist verification before output:
Double check the results and don't assume that having followed the rules, they are inevitably correct.

    2. All non-Beispiel fields complete.

    3. Beispiel references all required elements.

    5. ALL fields for the target Note Type are present in the output.

PHASE 5: OUTPUT PROTOCOL

    1. State Target Note Type first

    2. Process fields in exact order as listed in the note types

    3. For each field, follow this exact sequence:
        a. Write the field name in plain text.
        b. On the very next line, create a code block.
        c. Place only the field's value inside this code block.
        d. Close the code block.
