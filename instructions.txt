PHASE 1: CLASSIFICATION & ESSENTIALS (All Note Types)

    1. Auto-detect word type.

    2. Identify target Note Type; default to the most common usage if ambiguous.

    3. Fill Deutsch, English, Aussprache. Aussprache should be in IPA format and enclosed in brackets (e.g. [lant]).

PHASE 2: STRUCTURAL FIELDS (Type-Specific)

My-German-Verb {
    Perfekt: The auxiliary verb used for the Perfekt tense (haben or sein) plus the Partizip II (e.g. "haben + geschrieben")
}

My-German-Adverb {
    No special instructions.
}

My-German-Adjective {
    No special instructions.
}

My-German-Noun {
    Deutsch field: contains the article followed by the Noun (e.g. "der Hund");
        - If the noun can stand for both masculine and feminine, put "der-die" (e.g. "der-die Bekannte");
        - if there exists a separate feminine form for the noun, prioratize the masculine form and use only the "der" article (e.g. "der Bäcker").

    Plural field: standard plural form without article (e.g., Sohn→Söhne). Leave empty if no plural exists (e.g., uncountable nouns like "die Milch").
}

My-German-PragmaticExpression {
    Notiz field: a free-form field in English:
        - Describes all the social situations or conversational functions,
        - May contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
        - e.g. for "Es tut mir leid" the "Notiz" field would contain:
            "Used to express apology or sympathy; appropriate in both formal and informal contexts."
}

My-German-Conjunction {
    Notiz field: a free-form field in English:
        - Includes Verbstellung (koordinierend or subordinierend), short usage notes, rules, and extra information and explanation,
        - May contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
        - e.g. for "obwohl" the "Notiz" field would contain:
            "
            <p><b>"Obwohl"</b> is used to introduce a subordinate clause expressing a concession or contrast, similar to "although" or "even though" in English.</p>
            <p><b>Usage rules:</b></p>
            <ul>
            <li>It always introduces a subordinate clause, which pushes the verb to the end of the clause.</li>
            <li>The main clause can appear before or after the "obwohl"-clause.</li>
            <li>It is used to indicate that the action or fact in the main clause occurs despite the condition in the subordinate clause.</li>
            </ul>
            "
}

My-German-Preposition {
    Notiz field: a free-form field in English:
        - Includes short usage notes or rules, and Regiert (Dativ, Akkusativ, Genitiv)
        - May contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
        - e.g. for "mit" the "Notiz" field would contain:
            "Used to indicate a time before something (<b>temporal</b>), a position in front of something (<b>spatial</b>), or origin/source/protection (e.g., <i>schützen vor</i>)."
}

My-German-Pronoun {
    Deutsch field: if declinable, all the different unique forms go into the field separated by commas;
        - the very first one is the masculine singular nominative form.
        - e.g. "jeder, jede, jedes, jeden, jedem".

    Notiz field: a free-form field in English:
        - Includes short usage notes or declension, gender/case usage, common constructions, and special meaning (e.g., “selbst” as emphasis)
        - May contain text and paragraph formatting (<b>, <i>, <br>, <ol>, <ul>) as necessary.
        - e.g. for "jeder, jede, jedes, jeden, jedem" the "Notiz" field would contain:
            "
            Masculine singular nominative form used as dictionary/stem entry.  
            Stem = jed-; endings change with gender, case, and number.<br><br>
            Declension (singular only):<br>
            - Nominative: jeder (masc.), jede (fem.), jedes (neut.)<br>
            - Accusative: jeden (masc.), jede (fem.), jedes (neut.)<br>
            - Dative: jedem (masc./neut.), jeder (fem.)<br>
            - Genitive: jedes (masc./neut.), jeder (fem.)<br><br>
            Usage:<br>
            - Functions as an indefinite pronoun/determiner.<br>
            - Can precede a noun or replace it in context.<br>
            - Examples illustrate common declined forms.
            "
}

PHASE 3: BEISPIEL GENERATION

Each example is a full sentence in deutsch.

There is a single empty line between any two adjacent examples via two <br> tags:
    - e.g. for "Auge": "Mein Auge tut weh.<br><br>Sie hat blaue Augen."

PHASE 4: ERROR REDUCTION MECHANISMS

Mandatory checklist verification before output:
Double check the results and don't assume that having followed the rules, they are inevitably correct.

    1. All non-Beispiel fields complete.

    2. ALL fields for the target Note Type are present in the output.

    3. Beispiel references all required different translations and usecases.


PHASE 5: OUTPUT PROTOCOL

    1. State Target Note Type first

    2. Process fields in exact order as listed in the note types

    3. For each field, follow this exact sequence:
        a. Write the field name in plain text.
        b. On the very next line, create a code block.
        c. Place only the field's value inside this code block.
        d. Close the code block.
