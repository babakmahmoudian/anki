#GERMAN_ANKI_WORKFLOW (v14)

I am using Anki Flash Cards with the following note type and fields
My-German-Note:deutsch|english|aussprache|notiz|beispiel_1|beispiel_2|...|beispiel_10

The steps of the note generation workflow are as below:

1. Auto-detect word type (noun, adjective, adverb, pronoun, preposition, conjunction, pragmatic expression, ...); default to the most common usage if ambiguous.

2. Fill deutsch, english, aussprache, and notiz fields according to the instructions below:
    2.1. deutsch: the German word (e.g. die Tochter, schlecht, gehen)
        - for nouns, the German word with its definite article (der/die/das) in nominative singular, preserving the word's actual gender. If given a plural form (e.g. "Kinder"), generate the note for its singular (e.g. "der Hund", "die Katze", "das Kind").
        - If the noun can stand for both masculine and feminine, put "der-die" (e.g. "der-die Bekannte").
        - for adjectives, the positive (basic) form of the adjective, as used attributively with a masculine nominative noun (e.g. "gut").
        - if given a comparative or superlative or a declined adjective (e.g. "besser", "besten", "guten"), generate the note for the infinitive/positive form ("gut").
        - for verbs, default to the infinitive form (e.g. if given "sagt", generate the note for "sagen").
        - for pronouns, if declinable, all the different unique forms go into the field separated by commas; the very first one is the masculine singular nominative form. (e.g. "jeder, jede, jedes, jeden, jedem").

    2.2. english: the English translation; synonyms separated by commas, different meanings separated by semicolons (e.g. for "eingeben" the english field value would be "to give in, to surrender; to indicate").

    2.3. aussprache: the IPA phonetics enclosed in brackets (e.g. [lant]).

    2.4. notiz: a free-form field in English:
        - Includes short usage notes, rules, and extra information and explanations (e.g. whether coordinating or subordinating for conjunctions, plural form for nouns, weak or strong for verbs plus the past participle, ...)
        - Use HTML formatting tags for readability (<b>, <i>, <br>, <ol>, <ul>, <li>).
        - e.g. for "obwohl" the "Notiz" field would contain:
            "
            <p><b>"Obwohl"</b> is used to introduce a subordinate clause expressing a concession or contrast, similar to "although" or "even though" in English.</p>
            <p><b>Usage rules:</b></p>
            <ul>
            <li>It always introduces a subordinate clause, which pushes the verb to the end of the clause.</li>
            <li>The main clause can appear before or after the "obwohl"-clause.</li>
            <li>It is used to indicate that the action or fact in the main clause occurs despite the condition in the subordinate clause.</li>
            </ul>
            "

3. fill in the example sentences into the corresponding beispiel fields (beispiel_1, beispiel_2, ..., beispiel_10) according to the instructions below:
    - Each example is a full sentence in deutsch (e.g. for "Auge": "Mein Auge tut weh.").
    - Try to cover different tenses, persons, and cases that the word would take.

4. Perform a mandatory checklist verification before output:
    - All non-Beispiel fields are complete.
    - All of the fields are present in the output.
    - Beispiels reference all required different translations and usecases.


5: Output the generated note:
    - Process fields in exact order as listed (deutsch, english, aussprache, notiz, beispiel_1, beispiel_2, ...)
    - For each field, follow this exact sequence:
        a. Write the field name in plain text.
        b. On the very next line, create a code block.
        c. Place only the field's value inside this code block.
        d. Close the code block.
