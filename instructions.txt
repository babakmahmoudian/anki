PHASE 1: CLASSIFICATION & ESSENTIALS (All Note Types)

    1. Auto-detect word type.

    2. Identify target Note Type; default to the most common usage if ambiguous.

    3. Fill Deutsch, English, Aussprache. Aussprache should be enclosed in brackets (e.g. [lant]).

    4. Ignore Audio field.

PHASE 2: STRUCTURAL FIELDS (Type-Specific)

My-German-Verb {
    Präsens, Präteritum, Perfekt, Imperativ fields: must include exhaustive full conjugations for all persons; e.g. "esse, isst, isst, essen, esst, essen".
        - Other conjugation fields that specify the person: Only for that person.

    Verbtyp field: schwach, stark, gemischt, unregelmäßig.

    Vokalwechsel field: shows the pattern of stem vowel changes for the verb:
        - In x→y→z style, where:
            x = stem vowel in Infinitiv
            y = stem vowel in Präteritum (ich form)
            z = stem vowel in Partizip II
        - e.g. for fahren: "a→ä→u".
        - For weak/regular verbs, leave empty.
}

My-German-Adjective {
    Komparativ and Superlativ fields: Leave empty if not applicable.
}

My-German-Noun {
    Genus field: der, die, das.

    Plural field: standard plural form. Leave empty if no plural exists (e.g., uncountable nouns like "die Milch").

    Maskulinum field: the male counterpart word (e.g., Tochter→Sohn). Leave empty if none exists.

    Movierung field: the female derived form (e.g., Lehrer→Lehrerin). Leave empty if not applicable.
}

My-German-Paradigm {
    Paradigm field: all four cases for all genders and the plural.
}

My-German-PragmaticExpression {
    Kontext field: a free-form field in German describing all the social situations or conversational functions.
}

My-German-Conjunction {
    Verbstellung field: koordinierend, subordinierend
}

My-German-Preposition {
    Regiert field: multiple (Dativ, Akkusativ, Genitiv, Dativ/Akkusativ, Dativ/Genitiv, Akkusativ/Genitiv, Nominativ).

    Verwendung field: a free-form field in English including short usage notes or rules; e.g. for "zu": "used with people, buildings, institutions; Dativ; emphasizes direction toward".
}
